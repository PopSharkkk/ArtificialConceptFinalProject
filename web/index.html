Formulasi Matematis, Flowchart & Referensi

Landasan teoretis implementasi dua tingkat pada mata kuliah Konsep Kecerdasan Artifisial (EK234201).

Tier 1: Informed Search (Algoritma A*)

Menghitung lintasan aman terpendek antara dua koordinat di atas peta topografi berhalangan.

f(n) = g(n) + h(n)
h(n) = sqrt((x2 - x1)^2 + (y2 - y1)^2)
step_cost = dist_2D + max(0, delta_elevasi) * 0.004

Heuristik jarak Euclidean bersifat admissible (tidak pernah melebihi biaya sebenarnya), menjamin rute yang ditemukan optimal seperti Uniform Cost Search namun dengan simpul eksplorasi jauh lebih sedikit.

Tier 2: Local Search (Genetic Algorithm VRPTW-BL)

Mengoptimalkan pembagian posko, urutan kunjungan, isi ulang baterai di depot, serta batas waktu urgensi.

Obj = TotalCost + 0.35 * Makespan + 2.5 * Sum(UrgencyWeight * LateMin)
Operator: Tournament (k=3) + Order Crossover (OX) + Swap / 2-Opt Mutation

Urgensi Posko KRITIS memiliki bobot penalti keterlambatan 4x lebih besar dibanding SEDANG sehingga drone otomatis memprioritaskan pasien gawat darurat.
