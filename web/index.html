Formulasi Matematis, Adaptasi Dinamis & Referensi

Landasan teoretis implementasi perencanaan jalur adaptif pada mata kuliah Konsep Kecerdasan Artifisial (EK234201).

1. Informed Search (Algoritma A*)

Menghitung lintasan aman terpendek antara dua koordinat di atas peta topografi berhalangan.

f(n) = g(n) + h(n)
h(n) = sqrt((x2 - x1)^2 + (y2 - y1)^2)
step_cost = dist_2D + max(0, delta_elevasi) * 0.004

Heuristik jarak Euclidean bersifat admissible sehingga menjamin jalur 100% optimal dengan ekspansi simpul jauh lebih hemat dibanding UCS.

2. Local Search (Genetic Algorithm)

Mengoptimalkan pembagian posko, urutan kunjungan, isi ulang baterai di depot, serta batas waktu urgensi.

Obj = TotalCost + 0.35 * Makespan + 2.5 * Sum(UrgencyWeight * LateMin)
Operator: Tournament + OX + Swap / 2-Opt

Menyeimbangkan beban antar-armada dan memprioritaskan posko berstatus KRITIS.

3. Event-Driven Mid-Flight Re-Planning

Menangani rintangan baru (longsor susulan, tiang roboh) maupun rintangan bergerak (awan abu, sel badai) saat drone sedang mengudara.

Collision(Path_t..end, Obs(t)) == True
-> SplitState(pos_t, rem_batt, pending_camps)
-> Dynamic A* Re-plan dari pos_t

Drone meneruskan perjalanan dari koordinat udara saat itu tanpa harus kembali ke awal, serta otomatis menjadwalkan reload di Depot bila jalur memutar membutuhkan tambahan daya baterai.
